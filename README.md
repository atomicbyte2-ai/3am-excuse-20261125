# The 3 AM Excuse

> It's 3 AM — I don't sign for sleep-deprived humans. Your 'genius' trade can wait until your brain wakes up.

`main.ts` holds the entry line as a constant, validates it (1–199 characters, a single line, no newline or control characters), and writes it to `entry.txt` in the directory given by `MAKEFUN_OUTPUT_DIR` (default `/output`), with no trailing newline. It then reads the file back to confirm the bytes on disk match the validated line exactly and prints a short confirmation with the character count.
